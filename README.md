# Курсовая работа по дисциплине «Компьютерная графика»
## Тема: Визуализация объёмных данных методом Volumetric Raymarching

Проект представляет собой интерактивное веб-приложение для визуализации 3D-сканов (томограмм, научных и инженерных данных) в реальном времени. Приложение написано на C++20 с использованием модулей и скомпилировано в WebAssembly (WebGL 2.0).

---

## Реализованный функционал и алгоритмы

### 1. Графический алгоритм (Volumetric Raymarching)
* **Пересечение луча с AABB:** Вычисление точек входа и выхода луча из объема в пространстве модели.
* **Накопление цвета:** Итерирование по лучу с аккумуляцией цвета и оптической плотности во фрагментном шейдере (GLSL).
* **Устранение артефактов:** Псевдослучайный сдвиг начальной точки луча для сглаживания ступенчатых артефактов.
* **Пропуск пустого пространства:** Ускорение рендеринга путем увеличения шага интегрирования в областях с низкой плотностью.
* **Динамическое качество:** Автоматическое увеличение шага луча при перемещении камеры для сохранения высокого FPS.

### 2. Освещение и передаточные функции
* **Расчет градиентов плотности:** Вычисление векторов нормалей на CPU с использованием многопоточности (**OpenMP**).
* **Модель освещения:** Расчет диффузного и фонового освещения во фрагментном шейдере на основе 3D-текстуры нормалей.
* **Передаточные функции:** Отображение скалярных значений плотности в цвета и прозрачность через 2D-текстуры. Реализованы варианты: *Bone* (кости), *Muscle* (мышцы), *Rainbow*.

### 3. Архитектура и технологии
* **C++20 Modules:** Полный отказ от традиционных заголовочных файлов (`.h`/`.hpp`) в пользу модулей (`.cppm`).
* **Model-View-Presenter (MVP):** Разделение логики загрузки/обработки данных (`Model`), рендеринга (`View`) и управления состоянием (`Presenter`).

### 4. Пользовательский интерфейс и управление
* **Интерактивный UI (Dear ImGui):**
  * Переключение датасетов (Male Head, Engine Block, Carp) и 8-bit / 16-bit форматов (`.raw`).
  * Настройка параметров рендеринга: шаг луча, порог плотности, множитель прозрачности, направление источника света.
* **Система управления:**
  * "Летающая" камера (WASD + мышь с захватом курсора).
  * Поддержка сенсорных устройств: экранные виртуальные джойстики для мобильных браузеров.
